# Friedrich — СМС-наставник немецкого A0–A1

Android-мессенджер с ИИ-персонажем **Friedrich** на Gemini API (`gemini-3.1-flash-lite`).
Он сам пишет тебе «смс» в случайное время, ведёт досье твоих знаний и проводит по всей программе A0–A1.

## Что умеет

- **Пишет первым.** Случайные «смс»-задания весь день (5 уровней частоты, вплоть до «Тамагочи 🔥» каждые 4–15 минут), тихие часы, дневной лимит, «отложить на час». Утреннее «слово дня», вечерний итог, ворчит, если его игнорируют.
- **Ответ прямо из уведомления.** Уведомления в стиле мессенджера: «Ответить», «Отложить», «Прочитано». Нажатие открывает нужный чат.
- **Всегда включён.** Точные будильники, сторожевая проверка каждые 15 минут, автозапуск после перезагрузки, постоянный тихий сервис. Без сети задания приходят из встроенного офлайн-банка.
- **Знает всю программу A0–A1.** 47 тем со шпаргалками и таблицами: алфавит, числа, вопросительные слова, артикли, множественное число, падежи, спряжение, модальные глаголы, приставки, часы, даты, предлоги, Perfekt, бытовые ситуации, экзамен Goethe A1.
- **Досье ученика.** Словарь с интервальными повторениями, журнал ошибок, освоенность каждой темы, оценка уровня, факты о тебе, заметки и план Фридриха.
- **Твой материал.** Пришли список слов, текст, фото учебника, PDF, DOCX или голосовое — Friedrich сохранит список и будет отрабатывать его до освоения.
- **Режимы:** свободный чат, урок по теме, повторение слов, работа над ошибками, 14 ролевых сценок, блиц, «только немецкий», тест уровня, экзамен A1, отработка списка.
- **Чат:** сессии, закрепление, переименование, поиск, черновики, копирование, выделение текста, избранное, удаление, очистка, «переспросить», экспорт, вложения (фото, камера, файлы), голосовые, озвучка немецкого, кнопки быстрых ответов, панель ä ö ü ß.

## Как занести в репозиторий

1. **Удали старый код** `app/src/main/java/com/legode/app/` целиком (CbtScreen, SportScreen и т. д.). Иначе Hilt найдёт два класса Application и сборка упадёт.
2. Положи файлы из этого проекта по их путям (в папке `files/` каждый файл лежит по своему настоящему пути с добавленным `.txt` — убери `.txt` при копировании).
3. Бинарные файлы не обязательны:
   - `gradle/wrapper/gradle-wrapper.jar` — workflow скачает его сам;
   - `keystore/friedrich-debug.keystore` — workflow восстановит его из текстового `keystore/friedrich-debug.keystore.b64`.
4. Сделай push в `main` — GitHub Actions соберёт APK (артефакт `friedrich-debug`).

## Первый запуск

1. Получи ключ Gemini API: https://aistudio.google.com/apikey
2. На экране знакомства вставь ключ → «Проверить ключ».
3. Расскажи о себе, выбери частоту «смс».
4. Разреши уведомления и сними ограничение батареи. На Xiaomi/Huawei/Honor/Oppo/Vivo/Samsung дополнительно включи «Автозапуск» и «Без ограничений» для приложения.

## Архитектура (`com.legode.friedrich`)

| Пакет | Что внутри |
|---|---|
| `brain` | агент: Gemini-клиент с фолбэками, персона, программа A0–A1 со шпаргалками, сборка контекста, память и интервальные повторения, планировщик «смс», офлайн-банк заданий |
| `data` | Room-база (сессии, сообщения, словарь, списки, ошибки, темы, факты, дневник), настройки, шифрование ключа, вложения |
| `notify` | уведомления в стиле мессенджера, ответ из шторки, будильники, WorkManager, автозапуск, постоянный сервис |
| `audio` | голосовые сообщения, озвучка немецкого (TTS) |
| `ui` | Compose: чаты, чат, досье, справочник, настройки, знакомство |

Debug-сборки подписываются постоянным ключом (пароль `android`), поэтому новые APK ставятся поверх старых и данные не теряются.
